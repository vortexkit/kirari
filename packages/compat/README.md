# @vortexlabs/kirari

This package has been renamed to [`kirari`](https://www.npmjs.com/package/kirari).

`@vortexlabs/kirari` re-exports `kirari` on every entry point, so existing imports keep working and keep receiving updates. New projects should install `kirari` directly:

```sh
npm install kirari
```

To switch an existing project, replace `@vortexlabs/kirari` with `kirari` in `package.json` and in import paths. Nothing else changes.

Documentation: [kirari.sh](https://kirari.sh)
