# @vortexlabs/kirari

This package has been renamed to [`kirari`](https://www.npmjs.com/package/kirari) and is no longer supported.

`@vortexlabs/kirari` re-exports `kirari` and depends on it with a `^1` range, so existing imports keep working and follow `kirari` 1.x releases. It receives no further releases of its own, and it will not follow `kirari` 2.0 or later. To keep receiving updates, install `kirari`:

```sh
npm install kirari
```

Then replace `@vortexlabs/kirari` with `kirari` in `package.json` and in import paths. Nothing else changes.

Documentation: [kirari.sh](https://kirari.sh)
