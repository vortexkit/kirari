# @vortexlabs/kirari-react

This package has been renamed to [`kirari-react`](https://www.npmjs.com/package/kirari-react) and is no longer supported.

`@vortexlabs/kirari-react` re-exports `kirari-react` and depends on it with a `^1` range, so existing imports keep working and follow `kirari-react` 1.x releases. It receives no further releases of its own, and it will not follow `kirari-react` 2.0 or later. To keep receiving updates, install `kirari-react`:

```sh
npm install kirari-react
```

Then replace `@vortexlabs/kirari-react` with `kirari-react` in `package.json` and in import paths. Nothing else changes.

Documentation: [kirari.sh](https://kirari.sh)
