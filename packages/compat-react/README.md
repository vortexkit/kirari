# @vortexlabs/kirari-react

This package has been renamed to [`kirari-react`](https://www.npmjs.com/package/kirari-react).

`@vortexlabs/kirari-react` re-exports `kirari-react` on every entry point, so existing imports keep working and keep receiving updates. New projects should install `kirari-react` directly:

```sh
npm install kirari-react
```

To switch an existing project, replace `@vortexlabs/kirari-react` with `kirari-react` in `package.json` and in import paths. Nothing else changes.

Documentation: [kirari.sh](https://kirari.sh)
