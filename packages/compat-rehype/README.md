# @vortexlabs/kirari-rehype

This package has been renamed to [`kirari-rehype`](https://www.npmjs.com/package/kirari-rehype).

`@vortexlabs/kirari-rehype` re-exports `kirari-rehype` on every entry point, so existing imports keep working and keep receiving updates. New projects should install `kirari-rehype` directly:

```sh
npm install kirari-rehype
```

To switch an existing project, replace `@vortexlabs/kirari-rehype` with `kirari-rehype` in `package.json` and in import paths. Nothing else changes.

Documentation: [kirari.sh](https://kirari.sh)
