# @vortexlabs/kirari-rehype

This package has been renamed to [`kirari-rehype`](https://www.npmjs.com/package/kirari-rehype) and is no longer supported.

`@vortexlabs/kirari-rehype` re-exports `kirari-rehype` and depends on it with a `^1` range, so existing imports keep working and follow `kirari-rehype` 1.x releases. It receives no further releases of its own, and it will not follow `kirari-rehype` 2.0 or later. To keep receiving updates, install `kirari-rehype`:

```sh
npm install kirari-rehype
```

Then replace `@vortexlabs/kirari-rehype` with `kirari-rehype` in `package.json` and in import paths. Nothing else changes.

Documentation: [kirari.sh](https://kirari.sh)
