### Breaking changes

#### Renamed from `@vortexlabs/kirari` to `kirari`

The package is now published as `kirari`. `@vortexlabs/kirari` is deprecated and unsupported: it re-exports `kirari` 1.x, so existing imports keep working, but it gets no releases of its own and does not follow 2.0 or later. Switch to `kirari` to keep receiving updates.

**How to migrate**

1. Uninstall `@vortexlabs/kirari` and install `kirari`.
2. Replace every `@vortexlabs/kirari` import specifier with `kirari`, including subpaths such as `@vortexlabs/kirari/languages/python`.
3. Update any other mention of `@vortexlabs/kirari`, such as bundler configuration or `optimizeDeps` entries.

```sh
npm uninstall @vortexlabs/kirari && npm install kirari
```

```ts before
import { highlight } from '@vortexlabs/kirari'
import { python } from '@vortexlabs/kirari/languages/python'
import '@vortexlabs/kirari/theme.css'
```

```ts after
import { highlight } from 'kirari'
import { python } from 'kirari/languages/python'
import 'kirari/theme.css'
```
