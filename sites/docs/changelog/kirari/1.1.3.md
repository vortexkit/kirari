### Breaking changes

#### Public object types are type aliases

`Token`, `Rule`, `Language`, `RenderOptions`, `Decoration`, `TokenPatch`, and `TokenStream` are now type aliases instead of interfaces. Their members are unchanged, but code that extends them through declaration merging (module augmentation) no longer compiles.

**How to migrate**

1. Replace `declare module` augmentations of these types with your own type that intersects them, such as `type AppToken = Token & { line: number }`.
2. No change is needed if you only import and use the types.

### Bug fixes

- Markdown heading tokens no longer include the trailing line break, so heading styles and line-based renderers stop at the end of the line.
- JavaScript and TypeScript private class names such as `#count` are now one token, highlighted as properties at both the declaration and `this.#count`, and as functions for private methods.
