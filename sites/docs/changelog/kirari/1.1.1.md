### Improvements

- Reduce bundle overhead by consolidating function lookahead, simplifying equivalent JavaScript regexes, and sharing HTML escape replacements.

### Bug fixes

- TypeScript enum declaration names are now highlighted as types, like class, interface, and type alias names.
- JavaScript, TypeScript, and Python decorator markers are highlighted as operators and bare decorator names as functions, while qualified names and Python matrix multiplication retain their classifications.
