### Bug fixes

- Python annotated parameters after commas, such as `b` in `def f(a: str, b: str): pass`, are highlighted as variables instead of dictionary keys. Multiline signatures keep the same highlighting when streamed.
- Unparenthesized lambda parameters inside dictionaries, such as `b` in `{'f': lambda a, b: 1}`, keep their variable highlighting, including across streamed line breaks.
