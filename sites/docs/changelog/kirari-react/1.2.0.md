### Breaking changes

#### Renamed from `@vortexlabs/kirari-react` to `kirari-react`

The package is now published as `kirari-react`. `@vortexlabs/kirari-react` is deprecated and unsupported: it re-exports `kirari-react` 1.x, so existing imports keep working, but it gets no releases of its own and does not follow 2.0 or later. Switch to `kirari-react` to keep receiving updates.

**How to migrate**

1. Uninstall `@vortexlabs/kirari-react` and install `kirari-react`.
2. Replace every `@vortexlabs/kirari-react` import specifier with `kirari-react`, including subpaths such as `@vortexlabs/kirari-react/stream`.
3. `kirari-react` requires `kirari` as a peer dependency. If the project still uses `@vortexlabs/kirari`, migrate it to `kirari` the same way.
4. Update any other mention of `@vortexlabs/kirari-react`, such as bundler configuration or `optimizeDeps` entries.

```sh
npm uninstall @vortexlabs/kirari @vortexlabs/kirari-react && npm install kirari kirari-react
```

```ts before
import { Code } from '@vortexlabs/kirari-react'
import { useTokenStream } from '@vortexlabs/kirari-react/stream'
```

```ts after
import { Code } from 'kirari-react'
import { useTokenStream } from 'kirari-react/stream'
```
