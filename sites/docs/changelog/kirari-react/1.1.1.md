### Breaking changes

#### Public object types are type aliases

`Line` and `StreamedTokens` from `@vortexlabs/kirari-react/stream` are now type aliases instead of interfaces. Their members are unchanged, but code that extends them through declaration merging (module augmentation) no longer compiles. `CodeProps` remains an interface.

**How to migrate**

1. Replace `declare module` augmentations of these types with your own type that intersects them, such as `type AppLine = Line & { id: string }`.
2. No change is needed if you only import and use the types.
