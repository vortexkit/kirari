### Breaking changes

#### Renamed from `@vortexlabs/kirari-rehype` to `kirari-rehype`

The package is now published as `kirari-rehype`. `@vortexlabs/kirari-rehype` is deprecated and unsupported: it re-exports `kirari-rehype` 1.x, so existing imports keep working, but it gets no releases of its own and does not follow 2.0 or later. Switch to `kirari-rehype` to keep receiving updates.

**How to migrate**

1. Uninstall `@vortexlabs/kirari-rehype` and install `kirari-rehype`.
2. Replace every `@vortexlabs/kirari-rehype` import specifier with `kirari-rehype`.
3. `kirari-rehype` requires `kirari` as a peer dependency. If the project still uses `@vortexlabs/kirari`, migrate it to `kirari` the same way.
4. Update any other mention of `@vortexlabs/kirari-rehype`, such as bundler configuration or `optimizeDeps` entries.

```sh
npm uninstall @vortexlabs/kirari @vortexlabs/kirari-rehype && npm install kirari kirari-rehype
```

```ts before
import rehypeKirari from '@vortexlabs/kirari-rehype'
```

```ts after
import rehypeKirari from 'kirari-rehype'
```
